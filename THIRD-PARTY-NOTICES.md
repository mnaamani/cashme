## Embedded native code

into them. That code is inside the cashme binary too, and is listed here because it
does not appear in the npm dependency tree above.

- **librocksdb (RocksDB)** — Apache-2.0, via `rocksdb-native`  
  https://github.com/holepunchto/librocksdb — a fork of facebook/rocksdb, which is dual licensed Apache-2.0 and GPL-2.0; the fork carries the Apache-2.0 election. Portions derive from LevelDB, BSD-3-Clause, Copyright (c) 2011 The LevelDB Authors.
- **libjstl** — Apache-2.0, via `rocksdb-native, udx-native`  
  https://github.com/holepunchto/libjstl
- **libudx** — Apache-2.0, via `udx-native`  
  https://github.com/holepunchto/libudx
- **libsodium** — ISC, via `sodium-native`  
  https://github.com/jedisct1/libsodium — Copyright (c) 2013-2025 Frank Denis
- **Bare runtime** — Apache-2.0, via `bare-build`  
  https://github.com/holepunchto/bare, compiled into the standalone binary — which in turn embeds libuv (MIT) and V8 (BSD-3-Clause)
